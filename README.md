# Anastasiia Semerenko — портфоліо

Статичний сайт: https://semerenko-portfolio.vercel.app

Основа — експорт версії 201 (commit 2fbdc446f44bf06b7241247428adadea0e14a9b6), далі оптимізований і виправлений.

## Склад
- dist/index.html — головна (/).
- dist/education.html — RC PTO (/education).
- dist/pets.html — Prytulok (/pets).
- dist/landing.html — Synthetica (/landing).
- dist/portfolio-type.css — спільна типографічна система.
- dist/site.css, dist/site.js — спільні для всіх сторінок стилі й поведінка (підказки жестів, сенсорний скрол, футер, меню, переходи між сторінками). Нові спільні правки — сюди, а не новим блоком у кожну сторінку.
- dist/favicon.ico, apple-touch-icon.png, og-image.jpg — іконки й картка-прев'ю для соцмереж і месенджерів.
- vercel.json — статичне розміщення dist, адреси без .html, кешування, базові заголовки безпеки.
- export-manifest.json — перелік файлів і SHA-256 (`node _tools/manifest.js`).
- _tools/ — скрипти оптимізації та перевірки (не публікуються).

## Як оновлювати сайт
Репозиторій підключено до Vercel:
- push у `main` → автоматичний деплой на основну адресу;
- push в іншу гілку → окрема preview-адреса для перевірки (доступна після входу у Vercel).

Звичайний цикл: гілка → зміни → `node _tools/check.js` → push → перевірка preview на телефоні → merge у `main`.
Відкат: у Vercel → Deployments → потрібна версія → Promote to Production.

## Перевірки
`cd _tools && npm install` (один раз; для WebKit також `npx playwright@1.48.2 install webkit`).

| Скрипт | Що перевіряє |
|---|---|
| `check.js` | усі сторінки на десктопі й телефоні: помилки консолі, 404, зламані зображення, горизонтальний скрол (`ENGINE=webkit` — рушій Safari; `BASE=https://…` — живий сайт) |
| `swipe.js`, `swipe-items.js` | свайп пальцем у кожній горизонтальній каруселі, зокрема зі стартом на зображенні |
| `vswipe.js` | вертикальний свайп, що починається на екранах і мокапах, не «застрягає» |
| `hints.js` | підказки «Scroll/Swipe» стоять під своїм мокапом під час скролу |
| `reading.js` | затемнення тексту на головній збігається з оригінальною формулою |
| `no-video-all.js` | при заблокованому відео (енергозбереження iOS) видно перший кадр, а не чорний чи порожній екран |
| `videos.js` | усі відео відтворюються |
| `transitions.js` | переходи між сторінками без редиректів, з view transition |
| `lang.js` | переклади після перемикання на EN |

Скрипти, які раз змінили сторінки (`optimize.js`, `fix-alts.js`, `apply-fixes.js`, `inject-meta.js`), ідемпотентні: повторний запуск нічого не ламає.

## Що змінено відносно експорту
- Медіа: PNG/JPG → WebP, SVG-обгортки над PNG → WebP, MP4 перекодовано; 89 МБ → 7 МБ. Невикористані файли прибрано (є в історії git, коміт Baseline).
- Alt-тексти, favicon, canonical, описи сторінок, Open Graph.
- Мобільна /landing: заголовок не виходить за екран.
- Відео показують перший кадр, коли автозапуск заблоковано (енергозбереження iOS).
- Затемнення тексту на головній працює на CSS scroll-timeline (плавне навіть при урізаній частоті кадрів).
- Підказки жестів прив'язані до мокапів; свайп працює і зі стартом на зображенні.
- Лічильник проєктів — «барабан» цифр.
- Скляна кнопка меню; біла панель меню на темних сторінках; однаковий футер з перекладами.
- Плавні переходи між сторінками; внутрішні посилання без .html.

## Відомий технічний борг
Кожна сторінка містить понад 100 вбудованих блоків `<style>`/`<script>`, які послідовно перевизначають один одного (історія ітерацій). Перш ніж робити великі зміни, варто звести їх у спільні файли без зміни вигляду — перевірки вище якраз для цього.
