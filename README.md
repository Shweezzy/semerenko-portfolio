## Розміщення на Vercel
1. Розпакуйте архів.
2. Завантажте всю папку portfolio-vercel у власний Git-репозиторій та імпортуйте його у Vercel; або виконайте `vercel --prod` із цієї папки за допомогою Vercel CLI.
3. Root Directory — папка, де лежить vercel.json. Framework Preset — Other. Збірка не потрібна. Output Directory — dist.
4. Після публікації перевірте /, /education, /pets, /landing, перемикання UA/EN, інтерактивні мокапи, контакти й CV.

## Залежності та межі експорту
Усі 153 файли оригінального статичного сайту включено без зміни їхнього вмісту. Додані лише цей опис, vercel.json та контрольний маніфест. Серверна частина, база даних, npm-залежності й ключі API для роботи сайту не потрібні.

Використовуються системні шрифти Arial / Helvetica / sans-serif; окремих вебшрифтів у поточному проєкті немає. Усі наявні стилі включено. Зовнішні посилання CV (Notion) та LinkedIn збережено. PDF-копії CV у вихідному проєкті немає, тому вигаданий файл не додано. Clipboard API працює через HTTPS, який має забезпечувати хостинг.

Перевірено наявність усіх локальних src/href/poster/CSS url ресурсів та побайтову відповідність файлів вихідному проєкту. Відсутніх локальних ресурсів не виявлено. Фактичне розгортання на вашому акаунті Vercel і перевірку в браузері після перенесення не виконано.

Опублікований сайт у Sites не змінено. Історію Git та службові налаштування доступу Sites не включено: вони не є ресурсами сайту та не потрібні для Vercel.
